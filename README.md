# Alvin & Janice — Card Preview

A static wedding card demo for merchant review, using the photo arrangements from the supplied reference screenshot.

- **02 · The four moments:** four cherry-blossom wedding portraits with Alvin & Janice in the centre.
- **03 · The signature:** one grand-staircase portrait with script names on white side panels.
- Both designs preserve **18 × 5.4 cm** proportions.
- Responsive on desktop and mobile, with no editor, JavaScript, tracking, or external requests.

## Open the demo

Open `index.html` in a browser, or serve this repository's root with any static web host. No installation or build step is required.

For GitHub Pages, select **Deploy from a branch**, the `main` branch, and **/ (root)** in the repository's Pages settings.

## Print

Print from the browser at **100% / actual size**, with headers and footers disabled. The print stylesheet places both cards at **180 × 54 mm** on A4. This is a visual proof without production bleed or CMYK conversion.

## Assets

The repository includes only the five selected wedding photographs. The script names use SVG outlines so they render consistently without an installed font.
